- Media graph database (SQLite) access for media data management

- Desktop configuration via desktop.json

- Profile management via this-backend.json

mediamesh API

- Grafana integration for monitoring and UI

- Access key management for media library analysis

- Settings export/import for mesh configuration

occc-ui API

- Service monitoring endpoints (CPU/MEM meters)

- Activity density analysis data feeds

- Dashboard service status endpoints

Cross-Project Data Flow

  • truemotive-desktop → mediamesh: Media graph data (SQLite) shared via filesystem
  • truemotive-desktop → occc-ui: Activity density and monitoring data
  • mediamesh → occc-ui: Grafana access keys and monitoring configuration
  • All projects → Grafana: Centralized monitoring and analytics
